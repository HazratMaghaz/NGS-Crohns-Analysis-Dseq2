# Project Notes

## Objective

The objective of this project is to analyze RNA-seq count data from Crohn's Disease and control samples, identify differentially expressed genes using DESeq2, visualize sample-level and gene-level patterns, and perform Hallmark gene set enrichment analysis.

## Main Workflow

1. Load raw count matrix and sample metadata.
2. Prepare the DESeq2 dataset.
3. Perform normalization and variance-stabilizing transformation.
4. Visualize sample relationships using heatmap and PCA.
5. Run differential expression analysis.
6. Generate DEG result tables and volcano plot.
7. Perform Hallmark pathway enrichment using ranked gene statistics.
8. Save final figures and result tables.

## Notes

This repository is organized as a reproducible RNA-seq analysis portfolio project. It demonstrates differential expression analysis, visualization, pathway enrichment, and clean project structuring in R.
